# Jogo de Batalha Naval - Afundando o Navio

## Descrição

Este é um jogo simples de adivinhação em JavaScript, onde o jogador tenta adivinhar a localização de um navio em um intervalo de números. O jogador deve informar um número entre 0 e 5 para tentar acertar a posição do navio. O jogo continua até que o jogador acerte todas as posições do navio.

## Funcionalidades

- O jogo gera aleatoriamente a posição do navio.
- O jogador pode fazer tentativas de adivinhação.
- O jogo informa se o jogador acertou ou errou.
- O jogador não pode adivinhar o mesmo número mais de uma vez.
- Ao final do jogo, o jogador recebe um feedback sobre o número de tentativas e a precisão.

## Tecnologias Utilizadas

- JavaScript
- HTML (para execução em um navegador)

## Como Jogar

1. Abra o arquivo HTML que contém o código JavaScript em um navegador.
2. Quando solicitado, insira um número entre 0 e 5 para tentar adivinhar a localização do navio.
3. O jogo informará se você acertou ou errou.
4. Continue fazendo tentativas até que você acerte todas as posições do navio.
5. Ao final do jogo, você verá uma mensagem com o número total de tentativas e a precisão.
